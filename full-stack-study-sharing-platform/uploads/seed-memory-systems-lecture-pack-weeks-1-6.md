# Memory systems — lecture pack (weeks 1–6)

Working memory models, encoding vs retrieval, long-term potentiation basics, forgetting curves and study strategies that actually work.

## Outline

- Sensory memory and the modal model
- Baddeley's working memory model
- Encoding strategies: elaboration, chunking, dual coding
- Retrieval practice and spacing effects
- Ebbinghaus forgetting curve replications
- Sleep and memory consolidation

## Exam tips

Focus on being able to *compare* models rather than recite them. The long-answer question is almost always applied: expect a clinical case study.
